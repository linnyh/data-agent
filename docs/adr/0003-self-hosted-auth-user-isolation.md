# 自建账号认证体系 + 用户级数据隔离

本项目是独立部署的服务，无现成公司 SSO 可对接，因此自建认证：注册/登录、bcrypt 密码哈希、JWT 会话令牌，用户表自维护。数据权限为用户级隔离：会话与上传数据仅创建用户可见（owner_id 字段 + 权限检查），不引入组织/共享概念。

**Considered Options**: 对接现有 SSO/OIDC（无 IdP 存在，不可行）；无认证（独立项目可能对外部署，不可接受）。

**Consequences**: 不存储明文凭据的责任落在服务自身（bcrypt + JWT 过期策略）；认证与权限检查接口化，若未来出现统一 IdP 或组织共享需求，替换认证实现或扩展权限接口而不动业务层。
