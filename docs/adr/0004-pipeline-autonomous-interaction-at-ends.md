# 执行管线全自动，人机交互只在两端

对话式体验下，执行管线（视频预处理 → 相关性筛选 → 文档抽取 → 求解）保持全自动、零打断；人机交互只发生在管线两端：分析前的需求澄清（Agent 提问 → interrupt 挂起 → 用户回答 → resume）与分析后的结果解读、追问（用户发起新分析 = 新图调用，共享会话状态）。

**Considered Options**: 管线内可介入（关键环节先经用户确认再继续，用 interrupt 实现）——会破坏"无需人工干预"这一核心设计价值，且打断点让管线状态机复杂度倍增。

**Consequences**: 管线节点的输出不需要可展示的中间确认态；结果节点额外承担"叙述解读"职责（LLM 总结 + 表格数据）。
